# Descripción del Proyecto

SIMA es un sistema académico inteligente desarrollado bajo arquitectura MERN Stack que busca optimizar la gestión universitaria mediante procesos automatizados de matrícula, horarios y administración académica.

El sistema permite gestionar alumnos, carreras, docentes, cursos y horarios desde una interfaz moderna e intuitiva.

---

## Alcance Actual del Sistema

Actualmente el sistema administra:

- 3,000 alumnos
- 20 carreras
- 1,210 cursos
- 80 docentes
- 1,000 horarios y salones
