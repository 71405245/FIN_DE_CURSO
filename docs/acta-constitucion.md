## 📌 Propósito del documento

Este documento define la descripción general, los objetivos y los participantes del proyecto. Se relaciona principalmente con la autorización del inicio del proyecto.

Asimismo, brinda una descripción de la situación actual, los requisitos de alto nivel, criterios de éxito, riesgos y oportunidades.

---

## 🎯 Propósito / Justificación

El proyecto tiene como propósito organizar y estructurar la documentación del ciclo de vida del software, aplicando metodologías ágiles y buenas prácticas de gestión de proyectos en un entorno académico.

---

## 📌 Breve descripción del proyecto

El proyecto consiste en la creación de un repositorio estructurado en GitHub que permita gestionar toda la documentación del proyecto en sus diferentes fases: inicio, planificación e implementación, asegurando orden, trazabilidad y control de versiones.

---

## 📌 Alcance preliminar del proyecto

El proyecto incluye:

- Creación de estructura de repositorio en GitHub
- Documentación de fases del proyecto
- Gestión de backlog del producto y sprint
- Registro de riesgos, presupuesto e impedimentos
- Elaboración de informes de estado y minutas de reunión
- Desarrollo de software en producción



## 📊 Resultados esperados del proyecto / Beneficios

- Organización clara del proyecto en GitHub
- Aplicación de metodología Scrum
- Control de documentación
- Desarrollo de habilidades en gestión de proyectos
- Preparación para proyectos reales de software
