# 📋 1. Resumen ejecutivo

El proyecto **SIMA (Sistema Integral de Matrícula Académica)** tuvo como objetivo desarrollar una plataforma web inteligente orientada a optimizar la gestión de matrícula universitaria mediante:

- Generación automática de horarios personalizados.
- Administración académica integral.
- Motor de recomendación basado en restricciones académicas y operativas.

La solución fue desarrollada bajo una arquitectura:

> **MERN Stack**
>
> MongoDB + Express + React + Node.js

El proyecto fue organizado en **6 sprints**, ejecutados entre el **31 de marzo y el 22 de junio de 2026**, alcanzando un cumplimiento del:

# ✅ 100% del alcance planificado

- 👨‍🏫 Gestión administrativa y docente.

- 🤖 Generación inteligente de horarios usando:
