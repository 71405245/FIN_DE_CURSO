## Spec-Driven Development (SDD)

- [Constitution](constitution.md)

Documento que define los principios, reglas y restricciones no negociables para un proyecto específico. Actúa como la "constitución" del proyecto: establece los estándares arquitectónicos, las decisiones tecnológicas fundamentales, las guías de estilo, los contratos de API y las políticas de calidad que todo el código debe respetar. Tiene precedencia sobre cualquier otra consideración técnica.
---
- [Spec](Spec.md)

Documento técnico que describe con precisión las funcionalidades, requisitos, comportamiento y estructura de un componente de software o una aplicación completa, antes de que se escriba el código. Define casos de uso, interfaces, modelos de datos, flujos de trabajo y criterios de aceptación. Sirve como la única fuente de verdad para la implementación, pruebas y verificación del sistema.
