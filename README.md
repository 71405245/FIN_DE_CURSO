# 🎓 SIMA - Sistema Inteligente de Matrícula Académica

Sistema web inteligente orientado a optimizar el proceso de matrícula universitaria mediante la generación automática de horarios.

# 🎯 Objetivo del proyecto

El proyecto **SIMA** tiene como objetivo optimizar procesos mediante una solución tecnológica estructurada, aplicando buenas prácticas de ingeniería de software, gestión de proyectos y documentación técnica organizada.

---

# 🛠️ Tecnologías y enfoque

- Metodología: Ágil (Scrum)
- Enfoque: Ingeniería de Software orientada a calidad
- Documentación: Markdown
- Control de versiones: Git / GitHub
